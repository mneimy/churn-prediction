# 📓 Notebooks - Analyses et Storytelling

## Notebook Principal

### `01_data_storytelling.ipynb`

Notebook complet avec **9 sections d'analyse** qui racontent l'histoire du projet :

1. **📉 Le Problème** : Analyse exploratoire initiale
2. **🔍 Patterns de Churn** : Insights sur les délais et fréquences
3. **💰 Valeur Client** : Impact financier détaillé
4. **🎯 Segmentation RFM** : Analyse par segments clients
5. **📈 Performance Modèle** : Métriques et évaluation
6. **🔍 Features Importantes** : Interprétabilité du modèle
7. **💰 Impact Business** : Avant/après avec ROI
8. **📊 Dashboard Complet** : Vue d'ensemble
9. **📝 Conclusions** : Recommandations business

- `insight_days_since_last_order.html` - Impact du délai

- `segmentation_rfm.html` - Segmentation clients
- `model_performance.html` - Performance du modèle

## 🚀 Utilisation

### Exécuter le notebook

```bash
# Activer l'environnement
source venv/bin/activate

# Lancer Jupyter
jupyter notebook notebooks/01_data_storytelling.ipynb
```

Ou avec JupyterLab :

```bash
jupyter lab notebooks/01_data_storytelling.ipynb
```

### Exécuter toutes les cellules

Dans Jupyter : `Cell → Run All`

- Recommandations actionnables
