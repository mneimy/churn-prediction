# GitHub Pages - Churn Prediction

Cette page GitHub Pages présente le projet de prédiction de churn de manière visuelle et professionnelle.

## Configuration

1. **Activer GitHub Pages** :
   - Aller dans Settings → Pages
   - Source : `main` branch
   - Folder : `/docs`
   - Save

2. **Personnaliser** :
   - Remplacer `VOTRE_USERNAME` dans `index.html` par votre nom d'utilisateur GitHub
   - Remplacer les liens LinkedIn/contact si nécessaire
   - Modifier les couleurs dans `assets/css/style.css` si souhaité

3. **Accès** :
   - La page sera accessible à : `https://VOTRE_USERNAME.github.io/churn-prediction/`
